# Инженерная дисциплина для одного проекта

Переносимый набор правил: корневой `AGENTS.md`, четыре руководства и банк инженерных идей с первичными ссылками и реестрами. Документы читаются по задаче, а не все перед каждой правкой.

## Установка через агента

Открой нужный проект на другой машине и передай агенту промпт из [INSTALL.md](INSTALL.md). Репозиторий приватный: для скачивания нужен доступ владельца на GitHub. Можно использовать ZIP-копию вместо GitHub.

Агент добавит инженерный блок в корневой `AGENTS.md` и скопирует `docs/engineering/`. Существующие проектные правила сохраняются. Глобальные настройки и другие проекты не меняются. Если среда агента читает другой проектный файл инструкций, промпт предусматривает короткую ссылку на `AGENTS.md`.

Повторная установка обновляет один блок между комментариями `engineering-discipline:start` и `engineering-discipline:end`. До изменения существующих файлов агент сохраняет резервные копии и сообщает их расположение. Для отката восстанавливаются эти копии; удаляются только добавленные этой установкой файлы.

## Состав и происхождение

- [AGENTS.md](AGENTS.md) — принципы работы и условия чтения руководств.
- [Архитектура](docs/engineering/guidance/architecture.md), [состояние и интеграции](docs/engineering/guidance/runtime.md), [проверка результата](docs/engineering/guidance/verification.md), [окружение](docs/engineering/guidance/environment.md).
- [Банк инженерных идей](docs/engineering/knowledge/KNOWLEDGE.md), [происхождение правил](docs/engineering/knowledge/SOURCES.md) и связанные материалы.

Подготовлено 6 октября 2026 года из действующих личных инженерных инструкций. Инженерное ядро сохранено; абсолютные ссылки заменены относительными. Исключены инструкции конкретного Mac, VPS и Lenovo, скрипты обслуживания Codex и ссылки на них. Исходные файлы машины не изменены. Банк знаний перенесён вместе со всеми локальными файлами, достижимыми по его Markdown-ссылкам; дата и ограничения исходного исследования сохранены, повторное исследование не проводилось.

## Проверка пакета

Из каталога пакета запусти `python3 verify.py`. Проверка ищет недоступные локальные ссылки, зависимости от путей исходной машины, повреждённые JSON-файлы и нарушение границ инженерного блока. Внешние сайты и поведение другого агента эта проверка не подтверждает.
